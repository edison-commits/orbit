Support

Start with a safe next step.

A monitored public support channel and response-time promise have not been announced. These self-service checks cover the most common beta workflows.

No public download · No automatic cloud sync · No form submission

Reminders

Check consent and cadence

  1. In Orbit settings, confirm reminders are turned on.
  2. In system settings, allow notifications for Orbit.
  3. Confirm the person is active—not paused or archived—and has a due date.
  4. Return to Orbit settings and sync reminders again.

Contact import

Keep import read-only

  1. Allow Contacts access only if you want to import.
  2. Select the people you want to add; Orbit does not need write-contacts permission.
  3. If the picker is empty, review Orbit’s Contacts permission in system settings.
  4. You can always add a person manually instead.

Backup and restore

Protect the sensitive parts

  1. Confirm the backup connection test succeeds before creating or restoring a backup.
  2. Never share the service role key or a backup file.
  3. Make a fresh backup before restore if you may need to undo local changes.
  4. Remember that restore replaces local data and then resyncs reminders.

Need more help?

Orbit does not yet publish a support inbox through this site. Do not send passwords, private relationship notes, an address book, backup files, or service keys to an unverified contact. The contact page will be updated when an approved channel is available.
